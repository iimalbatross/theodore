# Happy Birthday Website 🎉

A beautiful, interactive birthday celebration website with animations, countdowns, and video gallery.

## Features
- 🎂 Interactive cake cutting animation
- ⏳ Countdown timer
- 🎥 Video gallery with 16:9 aspect ratio
- 💌 Memory wall with photo gallery
- ✨ Confetti and particle effects
- 🎵 Background music
- 📱 Fully responsive design

## Files
- `index.html` - Main HTML file
- `styles.css` - Styling and animations
- `script.js` - Interactive functionality
- Media files: 1-6.jpg, 1-3.mp4, sitaare.mp3

## Deployment
This website is ready to deploy on GitHub Pages. Simply push to your repository and enable GitHub Pages in the settings.

## How to customize
1. Update the name in `script.js` (line 1): `const herName = 'Rup';`
2. Replace media files with your own photos and videos
3. Update text and messages as needed
